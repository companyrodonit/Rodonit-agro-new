## Payload CMS (крок 3, зроблено 10.08.2026)

- **Стек**: payload 3.87.1 + @payloadcms/db-postgres + storage-vercel-blob, ESM
  (`"type": "module"`), withPayload у next.config.ts, фронтенд у `app/(frontend)/`,
  адмінка `app/(payload)/` (боілерплейт зі старого rodonit-new).
- **БД для розробки**: Neon Родоніта від rodonit-new, але ОКРЕМА схема **`redesign`**
  (`PAYLOAD_DB_SCHEMA=redesign` у .env.local) — 47 таблиць старого сайту в `public`
  не зачеплені. Прод піде у ВЛАСНУ базу клієнта, схема public (env не задавати).
- **Схема даних**: колекції users, media, categories, products (повна картка:
  specs/регламент/проблеми/SEO), cultures, solutions, distributors, blog-categories,
  posts; глобали home (hero+about+trust+cta) і settings (контакти/меню/юридичне/доставка).
- ⚠️ **Рядки «препарат + норма» живуть у культурах** (cultures.products), НЕ виводяться
  з регламентів препаратів: там культури вільним текстом із синонімами, точний збіг
  23/75. Ці ж рядки живлять фільтр каталогу і лічильники.
- **lib/cms.ts** — шар даних: геттери віддають ТІ САМІ структури, що статичні lib/*;
  БД недоступна → тихий фолбек на статику (білд без env перевірено — зелений).
  Сторінки ISR 300с. Клієнтські компоненти отримують дані пропсами з дефолтами.
- **Сід**: `npm run seed` (tsx --env-file=.env.local scripts/seed.ts) — переливає весь
  хардкод + картинки (упаковки/лого/обкладинки/фон hero) у CMS. Ідемпотентний.
  ⚠️ ПІСЛЯ здачі НЕ ганяти — зітре правки Олега.
- **Адмін**: reklama@rodonit.com.ua / Rodonit-2026-Redesign! (тимчасовий, Олег змінить).
  /admin перевірено браузером: дашборд українською, групи Система/Каталог/Контент/Блог.
- **Медіа**: локально public/uploads (gitignored), на проді Vercel Blob
  (BLOB_READ_WRITE_TOKEN). Без токена аплоад на Vercel не працюватиме (RO fs).
- **Граблі, які вже зловлено**:
  - payload CLI вимагає ESM → `"type": "module"` (CJS-файлів у проєкті не було).
  - Зміна поля колекції → drizzle push питає інтерактивно «create/rename?» і ВИСИТЬ.
    Поки даних мало: `drop schema redesign cascade` + перезапуск dev + `npm run seed`.
    На проді push вимкнено (`push: NODE_ENV !== 'production'`).
  - `robots.ts` у route group тихо випадає зі збірки → зроблено route handler
    `app/(frontend)/robots.txt/route.ts`.
  - Хардкод `rodonit-redesign.vercel.app` лежав у 14 файлах → тепер `lib/site.ts`
    (NEXT_PUBLIC_SITE_URL → VERCEL_PROJECT_PRODUCTION_URL → localhost).
  - Дані, що НЕ в CMS свідомо: тексти /privacy і /terms (авторські юр. документи,
    lib/legal.ts), блок «проблема→препарат» на головній (авторські тексти, lib/content).

### Що треба від Бро для прод-запуску CMS (крок 3-фінал)
1. Neon-база на акаунті клієнта (або дозвіл лишити на нашому) → POSTGRES_URL.
2. На Vercel проєкту rodonit-agro-new: POSTGRES_URL, PAYLOAD_SECRET (новий!),
   NEXT_PUBLIC_SITE_URL, BLOB_READ_WRITE_TOKEN (Storage → Create Blob store).
3. Прогнати `npm run seed` з прод-env (локально, .env тимчасовий) → контент+медіа в проді.
